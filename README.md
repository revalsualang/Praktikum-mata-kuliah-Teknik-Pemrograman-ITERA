## 📘 Deskripsi Modul

### 🔹 Modul 1 – Dasar Pemrograman Python

Berisi pengenalan dasar bahasa Python meliputi sintaks, variabel, tipe data, operator, struktur kontrol, fungsi, dan modularisasi.

### 🔹 Modul 2 – Struktur Data

Membahas penggunaan struktur data Python seperti list, tuple, set, dictionary, dan struktur data bersarang beserta studi kasus.

### 🔹 Modul 3 – Object Oriented Programming (OOP)

Menerapkan konsep OOP meliputi class & object, encapsulation, inheritance, polymorphism, serta studi kasus dan tugas akhir OOP.

### 🔹 Modul 4 – Library Python untuk Komputasi

Membahas penggunaan file handling serta library Python seperti NumPy, Pandas, dan SciPy untuk pengolahan dan analisis data.
